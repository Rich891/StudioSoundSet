# Acceptance Tests

MVP is complete only if:

1. Owner can create account.
2. Owner can create API Credential Set.
3. Owner can create Zone.
4. Owner can create Player Account.
5. Player can login and only see Player UI.
6. Player can connect Spotify.
7. Player loads Spotify Web Playback SDK.
8. Player becomes SDK ready.
9. Player sends heartbeat.
10. Admin sees Player online.
11. Admin imports a Spotify playlist.
12. App imports PlaylistTrack rows.
13. Playlist detail page shows songs.
14. Admin starts test playlist.
15. Player plays music.
16. Admin sees track, artist, cover, duration, position.
17. Admin sets volume.
18. Player confirms actual volume.
19. Admin pauses and resumes.
20. Admin skips.
21. Player Test Center runs all steps and reports success/failure.
22. No fake success states exist.
