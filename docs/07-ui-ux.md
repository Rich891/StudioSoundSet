# UI / UX

Design style:
- dark background
- neon bento panels
- large custom-looking icons
- large buttons with icon and text
- no tiny main actions
- modern control center aesthetic
- clear setup flow
- big now-playing cards
- strong status states
- loading, success, warning, error states

Admin Dashboard:
Top setup flow:
1. API credentials
2. Create player
3. Player login
4. Connect Spotify
5. Import playlist
6. Run player test
7. Create schedule

Player UI:
- kiosk-style
- big status
- zone name
- Spotify status
- SDK status
- current track
- cover
- volume
- last command
- instruction: set device system volume to 100%

Player Management:
- create player wizard
- player login credentials
- reset password
- player status
- test player
- open player URL

Playlist detail:
- cover
- metadata
- track sync status
- full track list

Calendar:
- real week calendar
- visible time grid
- Monday to Sunday
- 15 minute slots
- no pure block list
